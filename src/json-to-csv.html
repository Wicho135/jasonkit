JSON y CSV, ida y vuelta

              

                JSON es ideal para APIs y estructuras anidadas; CSV es el
                formato que entienden hojas de cálculo y herramientas de
                análisis. Este convertidor pasa de uno a otro sin instalar nada
                y sin subir tus archivos a un servidor.
              

              
De JSON a CSV

              

                Pega un array de objetos y obtendrás una tabla donde cada
                propiedad es una columna. Si activas el aplanado, las claves
                anidadas se convierten en rutas con puntos, como
                direccion.ciudad. Los valores que contienen
                comas, comillas o saltos de línea se escapan automáticamente.
              

              
De CSV a JSON

              

                Pega un CSV con cabecera y la herramienta generará un array de
                objetos. Puedes elegir el separador (coma, punto y coma o
                tabulación) y activar la inferencia de números y booleanos para
                obtener tipos nativos.
              

              
Descarga directa

              

                El botón de descarga genera un archivo .csv o
                .json en tu dispositivo. El CSV incluye BOM
                UTF-8 para que Excel muestre correctamente los acentos.
              

            


            

              
Preguntas frecuentes

              

                

                  
                    ¿Cómo se convierten objetos JSON anidados a CSV?
                  
                  

                    Activa la opción Aplanar objetos anidados. Las claves
                    internas se unen con puntos, por ejemplo
                    direccion.ciudad, y se convierten en
                    columnas independientes del CSV.
                  

                

                

                  
                    ¿Qué formato de JSON necesita el convertidor?
                  
                  

                    Puedes pegar un array de objetos o un objeto suelto. Cada
                    objeto se convierte en una fila y la unión de sus claves
                    forma las columnas.
                  

                

                

                  
                    ¿Se suben mis datos al convertir JSON a CSV?
                  
                  

                    No. La conversión se ejecuta por completo en tu navegador y
                    el archivo se genera localmente con un Blob descargable.
